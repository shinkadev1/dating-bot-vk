# История важных изменений

## 2026-11-03 — личная ссылка оплаты премиума (ветка paylink)

Кнопки «Купить премиум» в промо, воротах «Чата знакомств», клавиатуре диалога и отказе в медиа открывают личную ссылку Chat API вместо статичной `PREMIUM_URL`; из текста отказа в медиа убрана ссылка на сообщество. Причина: оплата должна узнавать пользователя без email. Зависит от маршрута `premium/link` ветки `payments` vk-bot; без него работает запасная статичная ссылка. Проверки: `compileall`, smoke-скрипт с подменённым Chat API. Живой VK и настоящий Chat API не проверены, не задеплоено.

## 2026-11-11 — контент вынесен в app/content для Bot CRM

Тексты, подписи кнопок, списки (города, пол, тарифы), раскладка и цвета клавиатур, картинки и описание экранов перенесены из `app/ui.py` и `app/assets/` в `app/content/content.json` и `app/content/images/`. `app/content.py` читает файл при старте и падает с `ContentError`, если чего-то не хватает. `app/ui.py` сохранил все прежние имена; команды кнопок (payload) остались в коде (`_BUTTON_COMMANDS`). Вынесены также тосты выбора города и текст «Премиум активен до …». Распознавание текстовых нажатий учитывает прежние подписи из `button_aliases`; поиск старых приветствий без кнопки сравнивает с текущим `COMMUNITY_GREETING` и прежней фразой «Нажми кнопку начать». Тесты больше не закрепляют конкретные подписи и позиции кнопок; добавлен `tests/test_content.py` (целостность ссылок и лимит ВК в 40 символов).

Проверки: снимок всех значений `app.ui` и JSON всех клавиатур (включая payload и цвета) до и после совпал (новые только добавленные имена); `pytest` — 14 тестов OK; pyflakes без новых замечаний. Не проверено: запуск с настоящим ВК.
